# Calculator with Tkinter

This is a simple and beginner-friendly Calculator Application developed using Python and the Tkinter library. The project provides a graphical user interface (GUI) where users can enter two numbers and perform basic mathematical calculations easily.

The calculator is designed with a simple and clean layout. Users can enter their first and second numbers in separate input fields and select an operation using the available buttons. The result is displayed instantly on the screen.

## Features

- **Addition (+):** Adds two numbers and displays their sum.
- **Subtraction (-):** Subtracts the second number from the first number.
- **Multiplication (*):** Multiplies two numbers and displays the result.
- **Division (/):** Divides the first number by the second number.
- **User-Friendly Interface:** Easy-to-understand graphical layout.
- **Input Fields:** Separate fields for entering two numbers.
- **Instant Results:** Displays calculation results directly in the application.

## Technologies Used

- Python
- Tkinter (Python GUI Library)
- Visual Studio Code

## How to Run the Project

1. Install Python on your computer.
2. Open the project in Visual Studio Code.
3. Save the Python file as `calculator.py`.
4. Open the terminal.
5. Run the following command:

```bash
python calculator.py
```

6. The calculator window will open.
7. Enter two numbers and click the operation button to get your result.

## Project Purpose

The main purpose of this project is to practice Python programming and understand how to create desktop applications using Tkinter. It helps beginners learn functions, variables, user input, button commands, event handling, and GUI development.

This project is a great starting point for anyone who wants to improve their Python programming skills and build interactive desktop applications.
